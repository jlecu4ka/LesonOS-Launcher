# LesonOS Launcher 🚀

![Version](https://img.shields.io/badge/version-1.0.0-orange.svg)
![Platforms](https://img.shields.io/badge/platforms-Windows%20%7C%20Linux%20%7C%20macOS-blue.svg)

Официальный лаунчер для Minecraft-сервера **LesonOS (Анархия)**. Создан на базе HeliosLauncher с упором на стабильность, обход блокировок и удобство для игроков из разных стран.

## ✨ Особенности

- 🛡️ **Обход блокировок (Playit.gg):** Встроенная поддержка глобального туннеля для игроков из Украины и других стран.
- 🌍 **Мультиязычность:** Полная поддержка русского (RU) и английского (EN) языков интерфейса.
- 🔒 **Оффлайн-авторизация:** Вход по нику без необходимости покупки лицензии (AuthMe).
- ⚡ **Оптимизация:** Предустановленный модпак Fabulously Optimized (Sodium, Lithium, Iris и др.).
- ☕ **Автоматическая Java:** Лаунчер сам скачает и настроит нужную версию Java 25, если её нет в системе.
- 🔄 **Автообновление:** Лаунчер сам проверяет и скачивает новые версии с GitHub.
- 📰 **Новости и статус:** Встроенный новостной блок и мониторинг статуса серверов Mojang.

## 🎮 Как подключиться

1. Скачайте последнюю версию лаунчера во вкладке **[Releases](../../releases)**.
2. Установите и запустите.
3. Введите свой игровой ник (от 3 до 16 символов).
4. Выберите сервер:
   - 🇷🇺 **LesonOS (RU)** — прямое подключение для игроков из РФ.
   - 🌍 **LesonOS (Global)** — подключение через туннель (для Украины и Европы).
5. Нажмите **ИГРАТЬ**!
